## 2. The list — work top-down (priority order)

### Tier 1 — Map / citation platforms (free, legit, fast — DO FIRST)
Real platforms, quick wins, build NAP authority. ~20 min each.

- [ ] **Yandex Business** — Yandex has real TR usage; claim + verify
- [ ] **Bing Places for Business** — Bing has ~5-10% TR share; import from GBP
- [ ] **Apple Business Connect** — appears in Apple Maps/Siri
- [ ] **Foursquare** (foursquare.com/products/claim) — feeds many other apps

### Tier 2 — Web-design directories (backlink + can SEND LEADS — highest value)
Agency-focused but accept solo/freelance. Free profile available on each (some upsell — skip the paid tiers for now). These give a quality backlink AND are where some buyers actually shop for designers.

- [ ] **Clutch.co** — create profile, add portfolio + the 5.0 reviews
- [ ] **DesignRush** — has a freelance web-designer category specifically
- [ ] **Sortlist** — Europe-focused, strong for web/design
- [ ] **GoodFirms** — free agency/freelancer profile
- [ ] **The Manifest** (Clutch sister site) — secondary profile

### Tier 3 — Designer portfolio profiles (relevant + profile backlink)
You're a designer — these are natural fits and let you link your site.

- [ ] **Behance** (Adobe) — portfolio + website link
- [ ] **Dribbble** — portfolio + website link
- [ ] **GitHub** — profile + pinned site link (you're a dev — legit)
- [x] **LinkedIn** — already have it ✓ (make sure website link is on the profile)

### Tier 4 — TR local authority (higher effort, higher value — the real needle-movers)
These are the geo-relevant links the research says matter most. Slower but worth it.

- [ ] **İstanbul Ticaret Odası (İTO) / TOBB member directory** — IF you're a registered business (şahıs şirketi counts for many). Member listings carry real local authority.
- [ ] **Local sponsorship / cause** — sponsor a small local meetup, student club, or nonprofit → ask for a link. One of these > 50 directory links.
- [ ] **Local PR angle** — offer a free site/audit to a local nonprofit or small business association → a mention/link on their site.

### Tier 5 — TR business directories (VET each before submitting — skip if spammy)
Some are fine, many are low-quality. Quick check: does the site look real, have actual traffic, and not be a wall of ads? If it looks spammy, skip it.

- [ ] **sahibinden.com** (business listing, if applicable)
- [ ] **Foursquare/Yelp Türkiye** (covered in Tier 1)
- [ ] Niche TR firma rehberi sites — only the clean, real-looking ones. **When unsure, skip.** A skipped spam directory costs nothing; a bad link can hurt.

## 3. Weekly cadence (the engine)
- **2-3 submissions/week.** Don't blast all at once (natural pace).
- Tier 1 + 2 first (fastest value), then 3, then chip away at 4 over the quarter.
- Log each on the scoreboard review. Re-check target-page positions monthly — links take 4-8 weeks to move rankings.

## 4. What NOT to do
- ❌ No "free backlink 100 sites" lists, no paid backlink packages, no link exchanges.
- ❌ Don't submit to obvious spam/ad-farm directories even if free.
- ❌ Don't vary your NAP — keep it byte-identical everywhere.
